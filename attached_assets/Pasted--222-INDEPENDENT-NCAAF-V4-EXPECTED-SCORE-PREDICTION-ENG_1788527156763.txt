============================================================
MISSION
============================================================

Build the first complete independent NCAAF V4 sports prediction engine.

This task is about predicting FOOTBALL.

It is NOT yet about deciding which bets TBM should publish.

The model must answer:

Given everything legitimately known before kickoff:

1. How many points should the home team score?
2. How many points should the away team score?
3. What is the expected margin?
4. What is the expected game total?
5. What is the probability each team wins?
6. What is the uncertainty/distribution around those forecasts?

NCAAF DATA
→ PIT-SAFE FEATURES
→ TEAM TRUE TALENT
→ OFFENSE
→ DEFENSE
→ MATCHUP
→ GAME CONTEXT
→ EXPECTED HOME POINTS
→ EXPECTED AWAY POINTS
→ SCORE DISTRIBUTION

→ TOTAL DISTRIBUTION
→ WIN PROBABILITY

PHASE 3 — EARLY-SEASON SHRINKAGE
============================================================

NCAAF has a major early-season sample problem.

Week 1 cannot be treated like Week 10.

Build explicit sample-size shrinkage.

Conceptually:

CURRENT TEAM STATE
=
w_current × current-season evidence
+
w_prior × prior-season evidence
+
w_population × population baseline

Weights should depend on sample size.

Example concept only:

0 games:
mostly prior-season/population

1 game:
heavy shrinkage

3 games:
moderate shrinkage

6+ games:
current season increasingly dominant

Do NOT blindly hardcode these example numbers.

Estimate or validate shrinkage using chronological data.

Store shrinkage state in diagnostics.
