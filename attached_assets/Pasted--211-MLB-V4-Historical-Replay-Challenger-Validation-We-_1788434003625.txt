#211 — MLB V4 Historical Replay & Challenger Validation

We have completed #210 — MLB V4 Sports Forecasting Challenger.

Current state:

- MLB V3 remains the official production champion.
- MLB V4 is implemented in the API.
- MLB V4 is running as a shadow challenger.
- MLB V4 does NOT publish official picks.
- MLB V4 does NOT affect units, ROI, notifications, Free Pick, Top Pick, Play of the Day, or champion learning.
- MLB V4 uses a run-first forecasting architecture.
- MLB V4 projects expected away/home runs before sportsbook evaluation.
- MLB V4 currently uses a normalized independent-Poisson outcome distribution.
- MLB V4 does NOT use deterministic game-ID probability noise.
- MLB V4 records uncertainty, data quality, feature completeness, unsupported features, run attribution, and probability attribution.
- MLB V4 currently uses calibration state UNFITTED_IDENTITY.
- Unsupported Statcast, defense, baserunning, pitch-type, reliever-quality, injury, and umpire inputs are explicitly recorded rather than fabricated.
- V4 shadow predictions and research outcome reviews are isolated from official production.
- Results/ROI were corrected to count only effective published picks.
- The legacy mutable learning path was removed/secured.
- V3 production behavior was preserved.

The purpose of #211 is NOT to improve V4 yet.

The purpose is to determine, using the largest clean point-in-time historical sample available, whether the V4 architecture is actually producing sensible, accurate, calibrated MLB forecasts.
