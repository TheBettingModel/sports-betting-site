==================================================

Use a SMALL predeclared candidate family.

==================================================

- predicted vs actual
- ECE

16. PROBABILITY SANITY
==================================================

All probabilities must be finite and valid.

Binary:

0 < p < 1

Soccer:

P(home) + P(draw) + P(away) = 1 within strict tolerance.

Reject NaN/Infinity/out-of-range results.
