#213 — MLB Point-in-Time Baseball Intelligence & Learning Dataset

We are continuing the MLB overhaul before moving to any other sport.

Previous work:

#210
Built MLB V4 as a separate run-first shadow forecasting challenger.

#211
Performed historical replay and challenger validation.

Key #211 findings:
- 79 clean PIT games
- V4 Brier: 0.2379
- V3 Brier: 0.2449
- Market Brier: 0.2331
- V4 Brier Skill vs market: -0.0206
- V4 total-run bias: -2.327 runs/game
- V4 total-run RMSE: 5.349
- insufficient sample for validation

#212
Diagnosed the V4 run-model bias.

Key #212 conclusion:

The -2.327 runs/game underprediction is real, but the existing historical data cannot isolate a defensible causal correction.

Important missing evidence includes:

- chronological point-in-time MLB league scoring environment
- confirmed historical lineups
- projected starter innings vs actual starter innings
- projected starter runs allowed vs actual starter runs allowed
- bullpen projected innings vs actual bullpen innings
- bullpen projected runs vs actual bullpen runs
- richer player-level and matchup data

Therefore:

- V3 remains production champion
- V4 remains shadow baseline
- V4.1 remains output-equivalent diagnostic wrapper
- no score-changing V4.1 formula change was justified
- no model should be promoted

==================================================
PRIMARY OBJECTIVE
==================================================

Build the permanent MLB Point-in-Time Baseball Intelligence and Learning Dataset.

This dataset must allow TBM to answer, over time:

1. What information did TBM know before the game?

2. What did TBM predict?

3. What actually happened?

4. Which components of the prediction were right or wrong?

5. Was the run projection wrong because of:
   - offense
   - starter
   - starter innings
   - bullpen
   - lineup
   - park/weather
   - run environment
   - another component?

6. Was the probability calibrated?

7. Did TBM outperform the point-in-time sportsbook market?

8. Did TBM beat the closing market?

9. Which features provide stable predictive value out of sample?

10. Which future model changes are supported by evidence?

This task is primarily:

DATA INFRASTRUCTURE
+
POINT-IN-TIME FEATURE CAPTURE
+
OUTCOME CAPTURE
+
LEARNING EVIDENCE

It is NOT a model-weight tuning task.
