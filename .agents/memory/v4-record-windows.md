description: Subscriber Record scope, provenance, and reset boundaries after the V4 transition.

The subscriber Record is strictly the settled official V4 ledger. Legacy and pre-cutover engine results must never enter the headline, recent results, ROI, or by-sport aggregates.

**Why:** Mixing a new 0–0 V4 record with historical engine performance made it unclear what the current product was measuring.

**How to apply:** “This Week” resets on Monday in America/New_York. “All Season” evaluates each row against that sport and league’s current season start, so split-year leagues and calendar-year leagues reset independently. Every by-sport row must use the same selected period as the headline.
